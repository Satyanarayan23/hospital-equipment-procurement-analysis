
# Hospital Equipment Procurement Analysis

## What Are We Trying to Solve?

Hospitals need to make informed decisions when purchasing medical equipment while managing procurement costs, supplier performance, warranty expenses, and equipment condition.

This Power BI dashboard brings these areas together, helping users explore procurement data, compare suppliers, understand costs, and monitor equipment conditions.

## What Each Page Shows

### 1. Hospital Equipment Procurement Analysis
Provides an overall view of hospital equipment procurement through key metrics and visual summaries.

### 2. Supplier Evaluation
Compares suppliers using procurement-related metrics and visualizations to help assess supplier performance.

### 3. Cost Analysis
Explores equipment procurement costs, including cost comparisons across equipment and other available categories.

### 4. Warranty Analysis
Presents warranty-related information and helps examine warranty periods and associated costs.

### 5. Equipment Condition Analysis
Shows the condition of hospital equipment through visual breakdowns, helping users review equipment status.
